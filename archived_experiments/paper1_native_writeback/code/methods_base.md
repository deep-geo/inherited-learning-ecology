# 后天行为偏好的代际保留及其生态收益边界

## 稿件状态

方法与结果工作初稿。当前先冻结方法表述；本轮原始比例写回结果完成后追加结果节。引言、相关工作与新颖性论证不在此稿中，不将尚未完成的文献审查写成已验证结论。

## 方法

### 生态系统与行动

研究采用32×32二维环面格点。每个格点最多容纳一个个体，并保存上限为1的局部资源。初始各格点以0.25概率被占据，个体初始能量为1.5，初始资源为1。每个sweep先在各格点补充0.06资源，再有放回抽取1024个格点进行异步访问。抽中活体时，首先以0.002概率发生背景死亡；幸存个体选择休息、采集或繁殖，行动能量成本分别为0.04、0.08和0.12。采集最多获得0.5局部资源，个体能量上限为4。

繁殖在行动成本支付后能量大于2且八邻域存在空位时成功。子代位置从空邻居均匀抽取，繁殖后亲子能量之和等于繁殖前剩余能量。基准各分得一半；生态边界实验改变子代份额为0.35或0.65，亲代保留互补份额。动作后能量非正导致能量死亡。所有背景死亡、能量死亡、出生和末期存活者均记录，末期存活者寿命按右删失处理。

### 遗传与生命周期状态

每个个体具有遗传表g和生命周期行为表theta。基准表示将能量与资源分别离散为8档，并加一个是否满足繁殖条件的二元状态，共128个状态、每状态3个动作值。出生时theta初始化为g；创始个体两表均为0。另一表示采用4×4×2状态，共96个动作值，用于检验分箱敏感性，不作为独立生态实现。

行动采用0.05探索率：以0.95概率在最大动作值间均匀选取，以0.05概率在三动作间均匀选取。访问某状态并执行某动作后，仅该坐标按theta(s,a)←theta(s,a)+eta[r−theta(s,a)]更新，基准eta=0.2。奖励是行动后保留能量减行动前能量，加0.2倍成功出生指示，减0.5倍能量死亡指示。繁殖时的保留能量包含亲子总量。

该更新估计即时局部动作回报，没有下一状态价值的自举项，因此应称即时动作价值学习，而不是标准带折扣回报的Q-learning。局部奖励不是种群适应度；其生态后果由完整资源、死亡与繁殖过程评估。

### 比例写回与固定幅度干预

原始规则定义学习位移delta=lambda_A(theta_parent−g_parent)，并令g_child=g_parent+delta。本轮lambda_A取0.25、0.5和1，另以lambda_A=0为无写回参照。独立突变在本轮设为0，以隔离写回，不据此推断突变与写回的交互。

在先前的方向隔离实验中，非零delta被归一化为固定L2幅度q=0.1841261006694567，以减少变异幅度差异对方向比较的干扰。本轮取消该归一化，不设置最小写入幅度，因此保留原始学习位移的大小。

主要随机对照在每个状态内将三动作更新分解为共同值m(1,1,1)和零和动作偏好c，在二维零和平面随机旋转c，同时保留m和c的范数。该方法匹配同一父代候选的状态支持、逐状态共同值和动作对比幅度；不将更新搬到其他状态。该对照仍含状态级学习信息，不是完全无信息的随机变异。不同群体生态轨迹分叉后，其出生次数、原始位移幅度和累计遗传量可以不同，因而不能将自然过程中的性能差直接称为每单位遗传量的因果收益。

### 后代重新学习的机制干预

先前机制实验在每种方向的512次非零遗传更新用完前保持各分支相同。自消耗最后一次更新的出生起，后续新生个体要么保留theta_child=g_child，要么将theta的每个状态三动作值设为该状态g的均值，清除表现型动作偏好。遗传参数g不变，此后也不再发生遗传写入。已存在个体不受干预。

对这些预算后出生个体分别设置学习率0、0.2或0.8。标准学习率下的清除损失为主要机制比较，快速学习是否缩小该损失为救援检验。提高学习率改变单次更新权重，没有提供额外生态交互或额外能量。不同方向到达预算上限的生态状态不相同，故同方向内部的干预比较是更直接的因果证据，不能据此声称完整中介效应。

### 本轮连接实验与统计

本轮在子代能量份额0.5和0.65下，分别运行无更新次数上限以及1024次非零更新上限。后者与先前固定幅度反转条件衔接；前者保留持续的比例写回。每个组合使用20个预先指定的新种子81000–81019。两环境、两额度、三个非零写回系数、两方向共480次运行，加每环境共享的无写回参照40次，共520次正式条件运行。52次开发运行使用80000–80001，仅用于实现检查。

主要终点为连续5个间隔200sweep的采样点占位至少95%的首次起始时刻。未在20000sweep内达到的运行保留，并以20000计入封顶时间，同时报告达到数、灭绝数、全过程占位AUC除以观察时长以及最后1000sweep的平均占位。90%和99%阈值作为辅助敏感性分析。封顶时间不代表未达到者的真实建立时间。

比较以随机种子为统计单位，并在相同种子条件间配对。使用20000次bootstrap重采样计算95%描述性区间，不进行多重比较校正，不以预算、时间点或同一生态运行内的子代充当独立样本。实验全部条件均报告，不按存活、达标或预算耗尽筛选。

### 复现与检查

保存全部逐出生遗传更新账、生态时间序列、寿命/删失记录、采样个体学习记录、参数与运行日志。审计包括人口收支、亲子能量守恒、更新范数、逐状态随机化不变量、不可达状态写入、累计遗传量和公式一致性。原始定向规则与旧引擎的非归一化实现核对；零学习与零写回分别在正确的同条件比较内检验，避免将有无生命周期学习误认为应产生相同轨迹。
