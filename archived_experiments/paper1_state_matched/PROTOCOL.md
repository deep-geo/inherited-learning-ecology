# 实验1与2：同状态动作方向对照与预算曲线（运行前冻结）

范围：只完成审查提出的实验1和2，不扩展新生态、表示或机制。继承上一轮L32,T20000,资源回补.06、死亡概率.002、eta.2、epsilon.05、384参数、g0=0、出生能量对半、出生奖励.2。初始25%随机占位。q固定0.1841261006694567，仍由旧开发数据定标。

新主要对照state_rotated_q：对每个状态s的三动作学习位移分解为d_s=m_s(1,1,1)+c_s，sum(c_s)=0。在二维零和动作平面均匀随机旋转c_s，保留该状态的m_s和||c_s||，不跨状态搬运位移。每次先将整个原始学习位移归一至q，再作逐状态旋转。因此对该父代的反事实定向候选，逐状态共同平移、动作对比范数、整状态范数以及状态支持均相同。三动作内部原有零坐标可以变为非零；不能称逐动作稀疏性也匹配。

此对照保留状态相关信息和共同动作值，只移除动作偏好的定向内容；不是完全无信息对照。不同生态条件分叉后不可能保证经历相同状态或群体累计动作对比能量相同。逐出生记录这些量，不能用原始L2匹配掩盖该限制。

条件：aligned_q（保留方向）、state_rotated_q（上述主要对照）、global_scrambled_q（旧全表打乱坐标/符号）、isotropic_q（旧全表各向同性随机变化），以及none无变异参照。旧对照用于显示改进随机几何后的影响，不替代新主要比较。

若aligned或state_rotated的原学习位移L2<1e-12，跳过该次遗传改变，不凭空制造可匹配状态支持；日志记录skip。额度按实际非零更新数消耗，未用满额度的死亡保留。全局随机对照始终按q更新；若出现skip，必须报告而不能声称所有出生范数完全一致。

主要指标：首次连续5个200sweep采样点占位≥95%的起始时间（800sweep采样跨度，不保证每步连续）。未在20000前确认达到者封顶记20000；同时报告达到数、灭绝、完整占位曲线、末1000采样占位平均、AUC/T。90/99%为预定辅助阈值。正式主比较只为aligned_q vs state_rotated_q，其余对比为参照。按seed配对bootstrap95%描述性区间，不做多重比较后的显著性宣判。

开发seed50000–50004：4变异条件×无限额/512上限×5=40次，加none5次，共45。只查实现，不按开发效果调整方案。
实验1独立确认seed51000–51019，无额度，5条件×20=100次。
实验2独立seed52000–52019，B={128,256,512,1024,2048}，4变异条件×5B×20=400次，none仅运行一次/seed作共享参照20次，共420。预算曲线用同seed配对，不把5个预算当100个独立seed。

预算报告：每run出生总数、实际非零更新数、sum L2及sum L2²；额外记录每次/累计动作对比范数平方与共同平移范数平方。只有用满的运行其总体L2预算才相等；主要分析不按用满筛选。

检查：逐状态均值/范数/对比范数/空状态支持一致性，物理不可达状态（能量bin0–3且can_divide=1）写入量，人口/能量守恒，额度、NaN口径，精确复跑。模拟程序增加匹配几何及同父代反事实探针诊断；评价随机流独立，测量不干扰生态。

输出：完整数据、代码、协议、真实开始结束/退出码/源哈希、报告及图。CPU最多4个模拟进程。声明仅适用于本模型，结果即使削弱原结论也完整保留。
